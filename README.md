# LIVE: Cut on the Beat

Rhythm game buat kru konser. Pilih kursi (Switcher atau Lighting Busker), pilih lagu, dan pastikan semua yang kamu lakukan jatuh tepat di ketukan.

- 9 lagu original (EDM, dangdut koplo, ballad). Semua musiknya dibuat langsung lewat Web Audio di dalam game.
- Satu file `index.html`, tanpa dependensi. Buka di browser, pakai laptop + headphone.

**Kontrol**
- Switcher: `1–4` pilih preview, `Spasi` TAKE.
- Lighting: `1–5` WASH / BEAMS / STROBE / SPOT / BLACKOUT.

**Bahasa / Language:** tombol `ID | EN` di menu. Otomatis English kalau browser bukan Bahasa Indonesia.

**Lagu dari YouTube (beta)**
1. Menu → Ganti lagu → tempel link YouTube → `+ MAP LAGU`.
2. Putar, tekan `T` di tiap ketukan (min. 8×) untuk mengunci tempo.
3. Putar dari awal, tandai bagian: `1` tenang · `2` build · `3` ramai · `4` drop · `M` momen · `E` akhir · `Z` undo.
4. Simpan → main. `KODE` menyalin beatmap untuk dibagikan.

Selama main: `Esc` atau tombol ✕ untuk pause / mengakhiri siaran.
